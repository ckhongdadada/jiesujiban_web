# 实验性功能与未启用模块

本文档记录项目中已实现但暂未启用的功能和模块。

## 1. 配置中禁用的功能

以下功能代码已完整实现，只需修改配置即可启用：

### 1.1 推测解码 (Assisted Decoding)

**配置项**：`feature_enable_assisted_decoding`

**当前值**：`false`

**功能说明**：使用小模型（Draft Model）加速大模型生成。小模型快速草拟若干 token，大模型批量验证，验证通过则直接接受，验证失败处重新生成。

**启用方式**：

```json
// configs/app/config.json
{
    "feature_enable_assisted_decoding": true
}
```

**环境变量**：
```bash
export QWEN_DRAFT_MODEL_PATH="./qwen_models/Qwen/Qwen2.5-0.5B-Instruct"
```

**代码位置**：
- `src/jsjb/reply_generation/qwen_lora.py` - 主生成模块中的推测解码集成
- `src/jsjb/reply_generation/experimental/speculative_decoder.py` - 完整的推测解码器实现

**适用场景**：生成模型升级到更大参数规模时，可显著提升生成速度。

---

### 1.2 详细日志 (Detailed Logging)

**配置项**：`feature_enable_detailed_logging`

**当前值**：`false`

**功能说明**：启用更详细的请求/响应日志记录，用于调试和问题排查。

**启用方式**：

```json

    "feature_enable_detailed_logging": true
}
```

**注意事项**：启用后日志量会增加，建议仅在调试时开启。

---

### 1.3 地理验证 (Geo Validation)

**配置项**：`feature_enable_geo_validation`

**当前值**：`false`

**功能说明**：对识别出的地名进行地理有效性验证，过滤无效或超出范围的地名。

**启用方式**：

```json
{
    "feature_enable_geo_validation": true
}
```

**代码位置**：`src/jsjb/ner/location_recognizer.py`

---

### 1.4 Neo4j 图数据库

**配置项**：`feature_enable_neo4j`

**当前值**：`true`（已启用）

**功能说明**：将内存知识图谱切换为 Neo4j 图数据库，支持更大规模图谱和持久化存储。

**配置方式**：

```json
{
    "feature_enable_neo4j": true,
    "neo4j_uri": "bolt://localhost:7687",
    "neo4j_user": "neo4j",
    "neo4j_password": "your_password"
}
```

**环境变量**：
```bash
export NEO4J_URI="bolt://localhost:7687"
export NEO4J_USER="neo4j"
export NEO4J_PASSWORD="your_password"
```

**前置条件**：
1. 安装 Neo4j 数据库（本地或远程）
2. 安装 Python 驱动：`pip install neo4j`
3. 创建数据库并设置密码

**代码位置**：`src/jsjb/knowledge/graph.py`

| 文件 | 说明 |
|------|------|
| `src/jsjb/reply_generation/experimental/speculative_decoder.py` | 完整的推测解码器实现 |
| `src/jsjb/reply_generation/experimental/fast_generation.py` | 快速生成实验 |

**使用方式**：

```python
from src.jsjb.reply_generation.experimental.speculative_decoder import get_speculative_decoder

decoder = get_speculative_decoder(
    target_model_path="Qwen/Qwen2.5-1.5B-Instruct",
    draft_model_path="Qwen/Qwen2.5-0.5B-Instruct"
)
result = decoder.generate("你好，请介绍一下北京的交通情况。")
```

## 4. Task Queue 模块

消息队列实现，用于异步任务处理：

| 文件 | 说明 |
|------|------|
| `task_queue/message_queue.py` | 消息队列实现 |

**适用场景**：
- 批量处理诉求
- 异步生成回复
- 后台任务调度

**使用方式**：

```python
from task_queue.message_queue import MessageQueue

queue = MessageQueue()
queue.enqueue({"type": "generate", "data": {...})
result = queue.dequeue()
```
