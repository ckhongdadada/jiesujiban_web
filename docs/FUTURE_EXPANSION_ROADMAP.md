## 2. 短期规划（1-2 个月）

### 2.1 更大 BGE Embedding 模型

**目标**：升级到 `BAAI/bge-large-zh-v1.5` 或 `BAAI/bge-m3`

**收益**：
- 更好的语义表示能力
- 长文本支持更好（bge-m3 支持 8192 token）

**风险**：
- 内存占用增加
- 推理延迟增加

### 2.2 推测解码

**目标**：为 Qwen 生成模型添加推测解码加速

**方案**：
```text
小模型快速草拟若干 token
  -> 大模型批量验证
  -> 验证通过则直接接受
  -> 验证失败处重新生成
```

**适用场景**：生成模型升级到更大参数规模时

### 2.3 单位先验矩阵

**目标**：构建 `unit_prior_matrix` 实现业务先验融合

**数据来源**：
- `unit_catalog` 单位目录
- 同区/同条线/上下级关系
- 名称相似度

## 3. 中期规划（3-6 个月）

### 3.1 Neo4j 图数据库

**目标**：将内存知识图谱迁移到 Neo4j

**收益**：
- 支持更大规模图谱
- Cypher 查询语言
- 持久化存储

**当前状态**：代码已支持 Neo4j 模式，需配置连接

### 3.2 主动学习闭环

**目标**：基于模型不确定性自动标注样本

**流程**：
```text
模型预测低置信度样本
  -> 人工标注
  -> 加入训练集
  -> 增量训练
```

### 3.3 多模态支持

**目标**：支持图片附件的诉求理解

**场景**：
- 垃圾堆积照片
- 道路破损照片
- 违规停车照片

## 4. 长期规划（6-12 个月）

### 4.1 端到端对话系统

**目标**：从单轮回复生成升级为多轮对话

**能力**：
- 追问澄清
- 进度查询
- 满意度回访

### 4.2 跨区协同办理

**目标**：支持跨行政区的复杂诉求

**场景**：
- 跨区道路问题
- 跨区河流治理
- 跨区公共交通

### 4.3 智能派单优化

**目标**：基于历史数据优化派单策略

**方法**：
- 强化学习
- 多目标优化（时效、满意度、成本）
