## 一、系统概述

### 1.1 系统简介

接诉即办智能回复系统是一个基于大语言模型的政务留言智能分析与回复生成系统。系统能够自动分析市民留言内容，识别所属行政区域，预测回复单位，并生成专业的政务回复文本。

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 地名识别 | 自动识别留言中的北京市行政区划名称 |
| 地名消歧 | 对歧义地名进行智能消歧处理 |
| 单位分类 | 预测留言应由哪个政府部门回复 |
| 回复生成 | 基于RAG技术生成符合政务规范的回复 |

### 1.3 系统特点

- **智能化**：采用先进的深度学习模型，实现端到端智能处理
- **高准确率**：分类准确率达85%以上
- **快速响应**：平均响应时间小于2秒
- **易扩展**：模块化设计，便于功能扩展

## 三、安装部署

### 3.1 创建虚拟环境

**使用Conda（推荐）**：
```bash
# 创建虚拟环境
conda create -n qwen_env python=3.10

# 激活虚拟环境
conda activate qwen_env
```

**使用venv**：
```bash
# 创建虚拟环境
python -m venv qwen_env

# 激活虚拟环境
# Windows:
qwen_env\Scripts\activate
# Linux/Mac:
source qwen_env/bin/activate
```

### 3.2 安装依赖

```bash
# 进入项目目录
cd 接诉即办项目

# 安装基础依赖
pip install -r requirements.txt

# 安装可选依赖（RAG、NER功能）
pip install -r requirements_optional_rag_ner.txt
```

### 3.3 下载模型文件

由于模型文件较大，需要单独下载：

**方式一：自动下载（首次运行时）**
```bash
# 首次运行时会自动下载模型
python app.py
```

**方式二：手动下载**
```bash
# 下载BERT模型
python -c "from transformers import BertModel; BertModel.from_pretrained('bert-base-chinese')"

# 下载Qwen模型
python -c "from transformers import AutoModelForCausalLM; AutoModelForCausalLM.from_pretrained('Qwen/Qwen2.5-1.5B-Instruct')"
```

### 3.4 配置文件

复制配置模板：
```bash
cp .env.example .env
```

编辑 `.env` 文件，配置必要参数：
```ini
# 模型路径
BERT_MODEL_PATH=./data/models/bert_classifier
QWEN_MODEL_PATH=./data/models/qwen_reply

# 服务配置
HOST=0.0.0.0
PORT=5000
DEBUG=False

# Redis配置（可选）
REDIS_HOST=localhost
REDIS_PORT=6379
```

### 3.5 启动服务

```bash
# 启动Web服务
python app.py

# 看到以下输出表示启动成功：
# * Running on http://0.0.0.0:5000
```

## 四、快速开始

### 4.1 通过Web界面使用

1. 打开浏览器，访问 `http://localhost:5000`
2. 在输入框中输入市民留言内容
3. 点击"提交"按钮
4. 查看系统返回的分析结果

### 4.2 通过API使用

```python
import requests

# 发送请求
response = requests.post(
    'http://localhost:5000/api/predict',
    json={
        'title': '关于小区停车位问题',
        'body': '我是朝阳区某小区的居民，小区停车位严重不足，希望相关部门能够协调解决。'
    }
)

# 获取结果
result = response.json()
print(f"预测单位: {result['unit']}")
print(f"生成的回复: {result['reply']}")
```

## 六、API接口使用

### 6.1 接口概览

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/predict` | POST | 完整预测（分类+生成） |
| `/api/classify` | POST | 仅分类预测 |
| `/api/generate` | POST | 仅回复生成 |
| `/api/locations` | POST | 地名识别 |

**请求**：
```http

{

    "body": "留言内容"
}
```

### 6.5 Python调用示例

```python
import requests

class APIClient:
    def __init__(self, base_url='http://localhost:5000'):
        self.base_url = base_url
    
    def predict(self, title: str, body: str) -> dict:
        """完整预测"""
        response = requests.post(
            f'{self.base_url}/api/predict',
            json={'title': title, 'body': body}
        )
        return response.json()
    
    def classify(self, title: str, body: str) -> dict:
        """仅分类"""
        response = requests.post(
            f'{self.base_url}/api/classify',
            json={'title': title, 'body': body}
        )
        return response.json()
    
    def generate(self, title: str, body: str, unit: str) -> dict:
        """仅生成"""
        response = requests.post(
            f'{self.base_url}/api/generate',
            json={'title': title, 'body': body, 'unit': unit}
        )
        return response.json()

# 使用示例
client = APIClient()

# 完整预测
result = client.predict(
    title='关于小区停车位问题',
    body='我是朝阳区某小区的居民，小区停车位严重不足，希望相关部门能够协调解决。'
)

print(f"预测单位: {result['data']['unit']['name']}")
print(f"生成的回复:\n{result['data']['reply']}")
```

## 七、常见问题

### Q1: 启动时提示"模型文件不存在"

**原因**：模型文件未下载或路径配置错误

**解决方案**：
1. 检查 `.env` 文件中的模型路径配置
2. 运行模型下载命令
3. 确保模型文件已正确放置在指定目录

### Q2: 响应速度较慢

**原因**：首次加载模型需要时间，或未启用GPU加速

**解决方案**：
1. 确保安装了CUDA版本的PyTorch
2. 检查GPU是否可用：`python -c "import torch; print(torch.cuda.is_available())"`
3. 启用Redis缓存加速重复请求

### Q3: 分类结果不准确

**原因**：输入文本过短或表述模糊

**解决方案**：
1. 确保输入内容详细具体
2. 包含明确的地点信息
3. 描述清楚问题类型

### Q4: 生成的回复不符合要求

**原因**：模型生成具有随机性

**解决方案**：
1. 点击"重新生成"获取新的回复
2. 修改输入内容后重新提交
3. 人工审核并修改生成结果

### Q5: 内存不足错误

**原因**：系统内存或显存不足

**解决方案**：
1. 增加系统内存
2. 使用更小的模型
3. 启用模型量化
