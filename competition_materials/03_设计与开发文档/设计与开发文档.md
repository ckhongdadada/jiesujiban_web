### 一、需求分析

#### 1.1 项目背景

随着数字政府建设的深入推进，各级政府部门通过"12345热线"、"领导留言板"等渠道接收大量市民诉求。传统人工处理方式存在效率低、响应慢、质量参差等问题，亟需智能化手段提升政务服务水平。

#### 1.2 用户需求

**主要用户**：政务服务热线工作人员、留言板管理人员

| 需求类型 | 具体需求 | 优先级 |
|----------|----------|--------|
| 功能需求 | 自动识别留言涉及的行政区划 | 高 |
| 功能需求 | 自动预测负责回复的政府部门 | 高 |
| 功能需求 | 自动生成符合规范的回复文本 | 高 |
| 功能需求 | 支持历史案例检索参考 | 中 |
| 非功能需求 | 响应时间小于3秒 | 高 |
| 非功能需求 | 分类准确率大于80% | 高 |
| 非功能需求 | 系统稳定性大于99% | 中 |

#### 1.3 系统边界

**系统内部功能**：
- 留言文本分析与处理
- 地名识别与消歧
- 单位分类预测
- 回复文本生成
- 知识库检索

**系统外部接口**：
- 用户Web界面
- RESTful API接口
- 地理编码API（可选）

##### 3.1.2 核心算法流程

```python
def disambiguate(self, text: str, location: str, candidates: list) -> DisambiguationResult:
    """
    地名消歧核心算法
    
    输入：
        text: 原始留言文本
        location: 待消歧地名
        candidates: 候选地名列表
        
    输出：
        DisambiguationResult: 消歧结果
    """
    # 1. 单候选直接返回
    if len(candidates) == 1:
        return self._single_candidate_result(candidates[0])
    
    # 2. 按行政区分组
    district_groups = self._group_by_district(candidates)
    
    # 3. 单行政区直接返回最优
    if len(district_groups) == 1:
        return self._best_in_district(candidates)
    
    # 4. 多行政区需要消歧
    # 4.1 计算上下文得分
    context_scores = self._calculate_context_scores(text, location, district_groups)
    
    # 4.2 计算地理编码得分
    geo_scores = self._calculate_geo_scores(location, district_groups)
    
    # 4.3 多源融合
    final_scores = self._fuse_scores(context_scores, geo_scores, candidates)
    
    # 5. 返回最优结果
    return self._select_best(final_scores)
```

##### 3.2.1 模型架构设计

```
输入层
├── 文本输入: [batch_size, seq_len]
└── TF-IDF输入: [batch_size, vocab_size]
        ↓
编码层 (BERT)
├── Token Embedding
├── Position Embedding
└── 12层 Transformer Encoder
        ↓
特征提取层
├── CNN分支: 3种卷积核 (3,4,5) → 拼接
├── Attention分支: Self-Attention → 加权求和
└── TF-IDF分支: 全连接降维
        ↓
融合层
├── 特征拼接: [CNN_feat, Attn_feat, TFIDF_feat]
└── 全连接: 768 → 512 → 109
        ↓
输出层
└── Softmax: 109类概率分布
```

##### 3.2.2 损失函数设计

```python
class RankAwareLoss(nn.Module):
    """
    考虑类别层级的损失函数
    
    对于层级相关的类别（如住建委-房管局），
    错误分类的惩罚与类别距离相关。
    """
    def __init__(self, gamma: float = 1.0, rank_penalty: float = 0.2):
        super().__init__()
        self.gamma = gamma  # Focal loss参数
        self.rank_penalty = rank_penalty  # 层级惩罚系数
        
    def forward(self, logits, targets, class_weights=None):
        # 1. 计算基础交叉熵
        ce_loss = F.cross_entropy(logits, targets, weight=class_weights)
        
        # 2. Focal loss调整
        pt = torch.exp(-ce_loss)
        focal_loss = ((1 - pt) ** self.gamma) * ce_loss
        
        # 3. 层级惩罚（可选）
        if self.rank_penalty > 0:
            rank_loss = self._calculate_rank_penalty(logits, targets)
            focal_loss += self.rank_penalty * rank_loss
            
        return focal_loss
```
